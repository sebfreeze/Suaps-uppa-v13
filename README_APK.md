## Génération automatique avec GitHub Actions
1. Copier le contenu de ce dossier à la racine du dépôt GitHub `sebfreeze/Suaps-uppa-v13`.
2. Ouvrir l'onglet **Actions** sur GitHub.
3. Choisir **Build APK SUAPS UPPA**.
4. Cliquer **Run workflow**.
5. À la fin du build, télécharger l'artifact **SUAPS-UPPA-V14-APK**.
6. Le fichier installable est `SUAPS-UPPA-V14.apk`.
